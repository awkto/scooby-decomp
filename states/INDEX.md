# Savestate route index

Savestates themselves are **not** committed (`states/*.state` and `runs/` are gitignored; they are
ROM-derived). Every state is regenerated by a deterministic harness script:

    tools/harness/h.sh tools/scripts/rooms/w0_r16.txt runs/out    # needs build/harness (see README)

then use `runs/out/room_w0_r16.state` with `load room_w0_r16` (copy the file into the run dir).
On the VMs: `tools/py/vmjob.sh warp` builds all of them under `runs/states/` in about a minute.

Rooms are reached through the game's own **password screen** (title -> PLAY ... -> CONTINUE), see
`docs/passwords.md` for the password format. The state is the world's initial game-state block, so these
are fresh-game states placed at each room. `Verified` = after the script `$FF06AA/$FF06AC` held the
expected mystery/room.

## Room -> script

* *password script*: fastest, always available (state = fresh game).
* *natural route*: found by random play from the real start (no password, no cheat), so story flags are
  whatever play produced; absent where random play did not reach the room. Frames = length of the route.

## Other scripts

* `tools/scripts/boot_title.txt` - boot to the title menu (state `titlemenu`).
* `tools/scripts/natural_w0.txt`, `natural_w1.txt` - real start of each mystery (lobby / first carnival room).
* `tools/scripts/debug_menu_w0.txt`, `debug_menu_w1.txt` - enter the pause-menu cheat code (A B A C A B Left Right A B Left)
  to unlock the DEBUG entries ROOMS / OBJECTS (see docs/passwords.md section Debug menu).
* `tools/scripts/test_replay.sh` - record/replay determinism check.
