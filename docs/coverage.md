Generated by `tools/py/covreport.py` from `data/exec_starts.txt` (merged harness coverage, see `tools/py/mergecov.py`)
and the instruction list of `src/scooby.s`.

* instructions in the code area (`$000200-$010FFF`, `$1F6D7A-$1F7081`): 14543

* functions (bsr/jsr targets + pointer-table entries): 259; fully covered 195, partially 45, never executed 19

How the coverage was gathered (all on a VM, see `tools/py/campaign.py`): password warps into all 51 rooms with
several flag sets (initial / all-ones / random), random no-pause play from each (normal, walk-biased and
pointer-mode presets), the hidden DEBUG pause menu (ROOMS / OBJECTS) entered with the cheat code, and random play
from the two real starts. Then (#29) scripted play through the verb UI: a crawler that tries every verb on every
object of all 51 rooms, and the story routes in `tools/scripts/story/` (see `docs/walkthrough.md`; `tools/py/story.py`).
The two long closed-loop walkthroughs (`w0_full`: Blake's Hotel from power-on to the credits; `w1_part`: Carnival up to the
Dart and the Ball, with the Crane Game and Bumper Car minigames) added 1121 instruction starts (83.6 % -> 91.3 %), mostly
cutscene, ending and minigame script sub-ops. Remaining gaps are script sub-operations of the unplayed Carnival chain (roller
coaster, bungee, Haunted House, Fun House choices, the Carnival ending) and a few handlers of the debug editors. (`loc_001C0C`, formerly listed as the
verb PULL handler, is the post-script handler of verb TALK (action_execute: `cmpi.w #8,d7`); the crawler's Talk
attempts execute it.)
