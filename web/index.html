You need your own ROM

This page is the C port of Scooby-Doo Mystery (Sega Genesis, 1995) compiled to WebAssembly. It contains no game data: it runs on the ROM of the original cartridge, which you have to provide yourself (a dump of a cartridge you own, the USA release, sha1 ).

The file stays in this browser: it is checked and kept in the page's IndexedDB so that later visits start straight away. It is never uploaded anywhere.
